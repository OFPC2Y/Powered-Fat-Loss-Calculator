# ⚡ 带电操作减脂食谱计算器

一个打开就能用的轻量减脂小工具：填完信息，一键生成「每天吃多少 → 三餐怎么吃 → 这几天买什么菜」的完整方案，还能保存成 PDF。

## 它能做什么

- **信息采集**：基础信息、工作与活动、饮食与生活、运动与作息、健康筛查五个板块
- **算每日目标**：根据情况估算基础代谢与每日总消耗，再按选择的减脂节奏给出「建议每日摄入」和热量缺口
- **配三大营养素**：优先保证蛋白质，再按约 25% 热量配脂肪，剩余热量给碳水
- **一键出食谱**：一日三餐或一日五餐（含两次加餐），每道食物都给出具体克数和做法
- **食材自由替换**：在「每天怎么吃」里用下拉框把蛋白质、主食、蔬菜、食用油换成你爱吃的
- **7 天采购计划**：一键生成采购清单！
- **现实执行检查**：生成后自动检查五件事——营养是否达标、食材种类是否适中、有没有买不了的小分量、菜是否容易放坏
- **保存 PDF**：点右下角按钮，导出 PDF下载留存

## 怎么用

1. 双击打开 `Powered-Fat-Loss-Calculator.html`静态网页
2. 填写左侧五块信息，重点填好「健康筛查」里的过敏与疾病情况
3. 点击「生成我的减脂方案」
4. 在「每天怎么吃」里用下拉框把食材换成自己方便的
5. 点击右下角「保存 PDF」

## 它的原理

- **每日能量**：用 Mifflin-St Jeor 公式估算基础代谢，再乘一个综合活动系数（工作性质 + 日常活动 + 运动 + 力量训练），得到每日总消耗
- **热量缺口**：根据选择节奏判断热量缺口——维持 0、温和 -300、标准 -500、较快 -700 kcal/天，目标摄入 = 总消耗 − 缺口
- **蛋白质**：按瘦体重估算（减脂约 2.0 g/kg，维持约 1.6 g/kg）
- **脂肪**：约占目标热量的 25%
- **碳水**：剩余热量全部给碳水

该方案给出的是**可执行的估算值**，并非绝对正确值。
建议按方案执行 2～3 周后，结合每周晨重（取 7 日平均）的变化再校准节奏。

## 健康筛查

- 有糖代谢异常、低血糖或明确疾病 → **不会**生成普通减脂方案，请咨询专业人士
- 有过敏或饮食禁忌 → 自动**排除**对应食材后重新配餐

## 注意事项

- 所有食材重量均为可食部分**生重**（米面为干重、肉类为生重、牛奶按 ml 计）
- 只使用内置食物成分表里已有的营养数据，表里没有的食物不会凭空估算
- 本工具面向普通健康成年人，结果仅作粗略减脂参考，**不构成医疗或营养处方**
