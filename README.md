# ⚡ 带电操作减脂食谱计算器

一个打开就能用的轻量减脂小工具：填完信息，一键生成「每天吃多少 → 三餐怎么吃 → 这几天买什么菜」的完整方案，还能保存成 PDF。

## 它能做什么

- **信息采集**：基础信息、工作与活动、饮食与生活、运动与作息、健康筛查五个板块，默认全部展开，填起来不用来回点
- **算每日目标**：根据你的情况估算基础代谢与每日总消耗，再按你选的减脂节奏给出「建议每日摄入」和热量缺口
- **配三大营养素**：先保证蛋白质，再按约 25% 热量配脂肪，剩余热量给碳水，不会出现「扣到负数」的极端情况
- **一键出食谱**：一日三餐或一日五餐（含两次加餐），每道食物都给出具体克数和做法
- **食材自由替换**：在「每天怎么吃」里用下拉框把蛋白质、主食、蔬菜、食用油换成你爱吃的，营养自动重算
- **7 天采购计划**：把食谱合并成一张采购清单，同类食材合并、贴近常见包装、提示易腐菜分批买
- **现实执行检查**：生成后自动检查五件事——营养是否达标、食材种类是否适中、有没有买不了的小分量、菜是否容易放坏、这一餐吃不吃得下
- **保存 PDF**：点右下角按钮，把整个方案（个人情况、每日目标、三餐、采购、检查、说明）导出成 PDF，直接下载留存

## 怎么用

1. 双击打开 `Powered-Fat-Loss-Calculator.html`，无需安装（默认示例：女 / 25 岁 / 165 cm / 60 kg，直接改成自己的即可）
2. 填写左侧五块信息，重点填好「健康筛查」里的过敏与疾病情况
3. 点击「生成我的减脂方案」——按钮滚出屏幕后，左下角会出现一个同款悬浮按钮，不用滚回去也能重新生成
4. 在「每天怎么吃」里用下拉框把食材换成自己方便的，系统会重新计算
5. 需要留存时，点右下角「保存 PDF」

## 它是怎么算的

- **每日能量**：用 Mifflin-St Jeor 公式估算基础代谢，再乘一个综合活动系数（工作性质 + 日常活动 + 运动 + 力量训练），得到每日总消耗
- **热量缺口**：你自己选节奏——维持 0、温和约 -300、标准约 -500、较快约 -700 kcal/天，目标摄入 = 总消耗 − 缺口
- **体脂率**：没填就按 BMI + 年龄估算（只用于估算瘦体重）
- **蛋白质**：按瘦体重估算（减脂约 2.0 g/kg，维持约 1.6 g/kg）
- **脂肪**：约占目标热量的 25%
- **碳水**：剩余热量全部给碳水

上面这些都是**可执行的估算值**，不是绝对正确值。建议按方案执行 2～3 周后，结合每周晨重（取 7 日平均）的变化再校准节奏。

## 健康筛查

- 有糖代谢异常、低血糖或明确疾病 → **不会**生成普通减脂方案，会提示你先咨询专业人士
- 有过敏或饮食禁忌 → 自动**排除**对应食材后重新配餐

## 注意事项

- 所有食材重量均为可食部分**生重**（米面为干重、肉类为生重、牛奶按 ml 计）
- 只使用内置食物成分表里已有的营养数据，表里没有的食物不会凭空估算
- 本工具面向普通健康成年人，结果仅作粗略减脂参考，**不构成医疗或营养处方**
